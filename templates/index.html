ABOUT THIS PROJECT

From Data Analysis to Prediction

This project combines data preprocessing, exploratory data analysis, statistical analysis, and machine learning to study responses to bank marketing campaigns.

The prediction model uses customer information available before a marketing call. Call duration is excluded because it is not known before the call takes place.

Model predictions are estimates and should not be treated as guarantees of customer behavior.
